# 🧩 13.1 — Primeiro módulo com bloco na Home

> Criação do módulo `Webjump_Emiliano` com Layout XML, ViewModel, template `.phtml` e CSS próprio.

---

## 🎯 Objetivo

Criar um módulo Magento do zero e exibir um bloco customizado na página inicial da loja.

O fluxo utilizado foi:

```text
Layout XML
    ↓
ViewModel
    ↓
Template
    ↓
HTML
```

O componente recebeu a identidade visual fictícia **Oak & Barrel**, utilizada nos exercícios da Sprint.

---

## ✅ Critérios de aceite

- [x] Módulo ativo no Magento
- [x] Bloco exibido na Home
- [x] Lógica concentrada no ViewModel
- [x] `.phtml` utilizado apenas para apresentação
- [x] Saídas dinâmicas escapadas
- [x] CSS próprio
- [x] Layout responsivo
- [x] Estrutura documentada

---

## 📁 Estrutura

O módulo foi criado em:

```text
src/app/code/Webjump/Emiliano/
```

Estrutura principal:

```text
Webjump/Emiliano/
├── registration.php
├── etc/
│   └── module.xml
├── ViewModel/
│   └── HomeMessage.php
└── view/
    └── frontend/
        ├── layout/
        │   └── cms_index_index.xml
        ├── templates/
        │   └── home-message.phtml
        └── web/
            └── css/
                └── home-message.css
```

---

## ⚙️ Implementação

### Registro do módulo

Os arquivos:

```text
registration.php
etc/module.xml
```

são responsáveis por registrar e declarar o módulo `Webjump_Emiliano`.

O módulo foi habilitado com:

```bash
bin/magento module:enable Webjump_Emiliano
bin/magento setup:upgrade
```

e validado com:

```bash
bin/magento module:status Webjump_Emiliano
```

---

### 🧠 ViewModel

O arquivo:

```text
ViewModel/HomeMessage.php
```

fornece os dados exibidos pelo componente, como:

- título;
- descrição;
- CTA;
- URL;
- destaques.

A lógica fica separada do template.

---

### 🖼️ Template

O arquivo:

```text
view/frontend/templates/home-message.phtml
```

é responsável apenas pela apresentação dos dados recebidos do ViewModel.

As saídas dinâmicas utilizam:

```text
escapeHtml()
escapeUrl()
```

evitando a renderização direta de valores sem tratamento.

---

### 🗺️ Layout XML

O bloco foi inserido na Home através de:

```text
view/frontend/layout/cms_index_index.xml
```

O Layout XML define onde o bloco será exibido e associa o ViewModel ao template.

---

## 🎨 Visual

O componente recebeu CSS próprio em:

```text
view/frontend/web/css/home-message.css
```

A identidade visual utiliza:

- fundo escuro;
- tons de âmbar;
- CTA destacado;
- seção de destaques;
- monograma `O&B`;
- comportamento responsivo.

No mobile, o layout passa de duas áreas para uma única coluna.

---

bin/cli php -l app/code/Webjump/Emiliano/ViewModel/HomeMessage.php

Resultado:

```text

```

---

## 🧯 Pontos resolvidos

Durante o desenvolvimento foram resolvidos dois problemas principais:

### VS Code e schemas XML

O VS Code inicialmente não reconhecia os URNs do Magento.

Foi gerado o catálogo de URNs e o projeto passou a ser aberto diretamente em:

```text
WSL: Ubuntu-22.04
```

### Git

O diretório `src/` estava sendo ignorado pelo `.gitignore`.

As regras foram ajustadas para permitir:

```text
src/app/code/
```

mantendo dependências como:

```text
src/vendor/
```

fora do versionamento.
